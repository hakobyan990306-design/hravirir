Հին շարժիչով (invites/engine) դիզայններից կատալոգում մնացել է միայն classic-green-ը (layout: "editorial")։ classic-gold, boho-engagement, baptism-sky, kids-party-ն կատալոգից հանված են՝ փոխարինված gold-gate, boho-arch, white-ribbon, balloon-sky-ով (ֆայլերը մնացել են, հին հղումները աշխատում են)։

## Կանոններ (տիրոջ դիտողություններից)
- Օրինակ-հրավերներում կոնկրետ հյուրի անուն չգրել (to:)․ հրավերը բոլորին է։ Անհրաժեշտության դեպքում՝ միայն ?to=... հղմամբ։
- Ռեստորանի/եկեղեցու ջրաներկ լուսանկարները չկրկնել դիզայնից դիզայն։ Ծրագրի կետերում՝ դիզայնի սեփական զարդը (.pic.ico), լուսանկար՝ միայն եթե հաճախորդն է տալիս իր վայրի նկարը։

## Պատվերի ձևը (invites/order.js)
- ՀԱՅ / РУС փոխարկիչ վերևում. լեզուն փոխելիս լրացված դաշտերը չեն կորչում, ընտրությունը հիշվում է (localStorage «ho-lang»)։
- Հրավերի էջում ձևը բացվում է հրավերի լեզվով, իսկ տեսակը գուշակվում է դիզայնի id-ից (baptism / ring, engage / gift, kids)։
- Հաղորդագրությունը գալիս է այն լեզվով, որով լրացվել է ձևը։

## Հաջորդ քայլեր
- Հին շարժիչով boho-engagement, baptism-sky, kids-party-ն փոխարինել նոր, առանձին դասավորություններով
- Pixabay-ի տեսանյութը (noir-sunset) ներբեռնել և պահել տեղում
- ORDER_ENDPOINT + Telegram բոտ (order-google-drive.gs)՝ նկարները ավտոմատ ստանալու համար

## Կառուցվածք
```
hravirir/
  index.html            ← գլխավոր էջ (կատալոգ, գներ, պատվեր)
  assets/site.js        ← գները, հեռախոսը, դիզայնների ցանկը (վերևում՝ ԿԱՐԳԱՎՈՐՈՒՄՆԵՐ)
  invites/engine/       ← բոլոր հրավերների ընդհանուր շարժիչը (չփոխել)
  invites/<դիզայն>/     ← 10 օրինակ-դիզայն
  clients/              ← այստեղ են լինելու հաճախորդների հրավերները
  fonts/                ← տառատեսակներ (fonter.am-ից և Google Fonts-ից)
  rsvp-google-sheets.gs ← մասնակցության հաստատման կոդը
  serve.js              ← տեղական նախադիտում (node serve.js → http://localhost:5500)
```

## Նոր հաճախորդի հրավեր (Claude-ի հետ)
Գրեք Claude-ին, օրինակ.
> Նոր հաճախորդ. դիզայն՝ navy-night, Արամ և Անի, 19.06.2027, եկեղեցի՝ ..., ռեստորան՝ ..., երկլեզու (hy+ru), դրեսկոդ, RSVP։ Նկարները՝ C:\...\photos

Claude-ը կստեղծի `clients/aram-ani/` թղթապանակը և կլրացնի ամեն ինչ։

## Ինքնուրույն
1. Պատճենեք `invites/classic-gold` թղթապանակը → `clients/aram-ani`
2. `index.html`-ում փոխեք `../engine/` → `../../invites/engine/` (2 տեղում)
3. Ջնջեք `demo: {...}` և `to: ...` տողերը (օրինակների նկարները՝ Unsplash-ից, փոխարինեք հաճախորդի նկարներով)
4. Լրացրեք `window.INVITE`-ի տվյալները։ Նկարները դրեք նույն թղթապանակում (`photo: "photo.jpg"`, `gallery: ["1.jpg","2.jpg"]`), երգը՝ `music: "song.mp3"`
5. Եթե լրացուցիչ ծառայություն չի պատվիրված, ջնջեք համապատասխան բլոկը (`dresscode`, `rsvp`, `tables`), իսկ լեզուների համար փոխեք `langs`-ը

## Անհատական դիմում յուրաքանչյուր հյուրին
Ծրարի վրա կարելի է գրել հյուրի անունը՝ հղման վերջում ավելացնելով `?to=`.
```
hravirir.am/clients/aram-ani/?to=Պետրոսյանների ընտանիք
```
Ծրարին կգրվի «Հարգելի՛ Պետրոսյանների ընտանիք»։ «Հարգելի՛» բառը փոխվում է `dear` դաշտով (օր.՝ `dear: "Սիրելի՛"`)։
Մեկ հրավեր, յուրաքանչյուր ընտանիքի համար՝ իր հղումը։

## Տառատեսակներ
Ամեն հրավերում՝ 2 տառատեսակ. մեկ գեղագիր (ArmAllegro, ArmCoronet, SHK Dzeragir կամ Armmatura) և GHEA Mariam։
Ռուսերեն տարբերակում գեղագիրը փոխարինվում է Marck Script-ով (հայկական գեղագրերը կիրիլիցա չունեն)։
Գլխավոր էջում՝ նաև Noyemi և Cinzel։

Ծրարի տեսակը ընտրվում է ըստ թեմայի, բայց կարելի է փոխել՝ `envelope: "v" | "round" | "arch" | "wide" | "scallop" | "ribbon" | "kraft" | "confetti" | "doors" | "diamond"`։
fonter.am-ի տառատեսակների մի մասը կոմերցիոն օգտագործման համար կարող է լիցենզիա պահանջել. ստուգեք fonter.am-ում։

## Հրապարակում (Netlify, անվճար)
1. Գրանցվեք app.netlify.com-ում
2. Առաջին անգամ ամբողջ `hravirir` թղթապանակը քաշեք app.netlify.com/drop-ի մեջ
3. Domain settings → Add domain → `hravirir.am`։ Դոմենը գնեք .am գրանցողի մոտ (օր.՝ am.am, arminco), և DNS-ում դրեք Netlify-ի ցույց տված գրառումները
4. Ամեն նոր հաճախորդից հետո նորից քաշեք թղթապանակը (Deploys → drag & drop)։ Հաճախորդի հղումը կլինի `hravirir.am/clients/aram-ani/`
